# 战场紧迫感与代入感：导演专项

仅适用于有战争、袭击、爆炸、撤离等情境且需要紧迫感的作品。保留用户选定剧情、风格、角色数量、时长和生成授权；本规则不自动发起制作或付费重试。不提供实拍爆破操作或真实武器反制参数。

## 1. 先写压力链，而不是特效清单

每个主要威胁写成：已存在的战事 → 可被察觉的刺激 → 人物感知 → 立即受迫行动 → 可见后果 → 危险留下的状态。每个镜头至少说明本镜头承接哪项压力；不要求每镜都新增爆炸。

为每一事件记录：event_id、起止时间、空间位置/来向、威胁对象、可见/可听线索、各人物响应、掩体或逃避方向、相机响应、持续后果、证据时间码、审核状态。编剧事件、Blender关键帧、声音设计、图像资产、成片检查使用相同event_id，不能文字里有而预演里没有。

区别三层，不机械固定数量：

- 远景战事：在人物对白时仍发生且前后保持方向的炮火亮点、爆点、烟柱形态变化等。静态烟柱只能建立曾经交战，不能单独证明当前正在打。
- 中景压力：封住通路、逼近撤离点或迫使人物换位的事件。
- 近景求生：近旁冲击、扑低、扶稳、收枪、拖回掩体、护住装备等实际行动。至少一个关键威胁需要改变人物正在做的事，而不只是让他做个表情。

“无杂色、克制细节、无繁杂纹理”约束材质和视觉噪声，不删除必要的战事。用少量清楚的大形态、不同深度与发生时机建立战场，不堆密集火星、碎屑或满屏烟尘。保持原有角色和关键道具数量；确需新增主体时明确提出，不默默扩充。

## 2. 人物不是等候台词的演员

写清刺激之前的姿态与视线：已在掩体后戒备的反应和完全意外的受惊不同。角色可以先察觉声音再躲避，必须给出线索；不能毫无线索提前知道爆点，也不能等爆炸完、说完台词才反应。

让不同人物采取符合各自位置的行动：避向哪一侧、哪条腿支撑、手抓何处、如何保护持有物、是否打断对白。脸部表情跟随动作变化，不代替行动；反应不复制成三人同时同幅度点头。躲避后保留喘息、低姿、重心不稳或继续警戒，不立即恢复合影站位。

战争喜剧的笑点应来自压力下的地位反转、嘴硬失效或狼狈求生。不要为完整展示笑脸停止威胁。压缩或中断炫耀对白，把讨好和让位安排在低身移动中，不让危险暂退变成场景完全安全。

## 3. 无人机等逼近威胁：建立碰撞预期

明确它冲向哪里、人物为什么知道冲自己来、他们还有什么躲避余地。飞行目标相对固定地标（车门、掩体边缘、人物）应可读地接近、放大或横穿视野；不能只让无人机居中、镜头同速跟随、空背景均匀滑过，最终像产品展示。

推荐依据本片选择“角色察觉 → 主观方向找到目标 → 威胁与人/掩体同框 → 人物动作被打断”的信息次序，不强制固定镜头数或时长。必要近跟镜头应短且保留目标车辆的距离变化，再回到人物承压的空间立场。避免飞行器悬停、绕圈或减速等待操作。

按真实场景尺度检查飞行距离、可用反应时间和切镜时间；反制特写期间威胁持续运动，不能隐性停表。截击/反制的开始、过程、结果要有画面，不拿爆白替代触地，不虚称虚构设备能保证真实拦截。

## 4. 镜头震动与近旁爆炸

为每次震动注明触发事件、来向、起点、冲击偏移、回弹/衰减、重新取景对象及必须保持可读的动作。至少区分正常跟随的轻微起伏、摄影机主动避让、爆炸造成的瞬态冲击，不能全片套同一随机抖动。

观感应是冲击突然打断取景，随后可控地找回人物或威胁；镜头不应提前无因震动。幅度和衰减由具体画面测试确定，不把一套角度/帧数强加所有片子。预演显式实现事件相关位移/转动，后期震屏只能补质感，不能替代躲避、受力和重新构图。

用户说“零距离爆炸”时，默认解释为镜头近旁强烈冲击观感，并在导演稿说明。爆点可在装甲/掩体另一侧，闪光、沙土、碎屑运动和车体振动进入近前景，人物及时收回掩体；不能把爆心放在无防护人物脚下又让其毫无影响，除非用户明确选择非写实夸张。保留遮蔽关系，不伪造安全距离、爆破工程或医学结论。

特效短暂影响视野可以成立，但关键操作、命中与结果必须重新可见；震动和烟尘不能成为逃避穿模、接触和因果检查的遮罩。

## 5. 代入感与声音

为主观察立场设定与人物同处的空间风险和有限视野。用门框/掩体近前景、身体掠近镜头、威胁从画外进入、受迫俯低后的视角变化体现距离；不新增不必要角色或凭空移动镜头穿过装甲。

声音稿说明方向与距离变化、对白被冲击打断、近处呼吸/装备碰撞和远处持续交火。不能单靠音效把安静图像解释成战争。预演仍无音轨，声音事件另表记录；最终视频声音按原授权生成。禁止擅自增加配乐、字幕、倒计时HUD来弥补视觉压力不足。

## 6. 预演和成片的放行检查

逐项写PASS / FAIL / UNVERIFIED / NOT NEEDED及当前文件哈希、具体时间码；不以文档包含关键词作通过标准：

1. 不看字幕/提示词，能否辨认当前交战、主要威胁来向与受威胁对象？
2. 背景战事在对白期间是否仍有可见变化，而非静态荒地加环境声？
3. 至少一个危险事件是否真正打断动作/对白并改变站位、姿态或路线？
4. 威胁是否连续逼近，操作期间是否仍前进，躲避时机是否有感知线索？
5. 镜头震动是否与冲击关联、衰减并重新找回事件，而非无因乱抖？
6. 近旁爆炸的遮蔽、人物反应及留下状态是否一致，不是贴片火球？
7. 关键因果是否仍能看清，喜剧是否来自求生状态而非停下摆表情？
8. 首帧、预演和外观参考是否都支持此空间压力，没有互相冲突的静态站位？

导演意图FAIL先修脚本/预演/必要首帧，不仅加长提示词。几何、解码、素材计数通过不能覆盖导演关卡失败。动态项目按主技能的实际视频观看要求验收；无法观察则如实标记并按其缺口处理规则执行，不自动豁免。新付费重试仍须用户授权。
