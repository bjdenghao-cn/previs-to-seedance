# 使用说明

本说明面向实际执行项目。Skill 的完整约束以 `previs-to-seedance/SKILL.md` 为准。

## 1. 开始前提供什么

至少说明以下信息；暂时未知的项目可以标记“待定”，不要让模型自行锁定会改变创意方向的关键选择。

- 故事或创意目标
- 目标风格：真人、3D 写实、2D 卡通或其他指定风格
- 画幅、时长、数量
- 一镜到底或允许切镜
- 已有的角色、场景、道具、首帧和参考视频
- 希望参考的 Higgsfield 运镜片段及时间范围
- 当前只做脚本、预演、提示词，还是已授权最终生成

## 2. 阶段与交付物

| 阶段 | 主要交付 | 放行条件 |
|---|---|---|
| 导演脚本 | 剧情稿、导演稿、导演自审表、`storyboard.json` | 故事、动作因果、镜头立场和结束状态明确 |
| 运镜标准 | 参考来源、查看时间段、构图/FOV/路径/视差/节奏标准 | 已实际查看素材；观察与推断分开记录 |
| Blender 预演 | `.blend`、24 fps 无声 Playblast、检查记录 | 穿模、接触、移动、因果和运镜对照通过 |
| 风格参考 | 素材清单、预演帧映射、图片审核状态 | 每个主要主体和阶段均有足够的目标外观覆盖 |
| 提示词与提交 | 提示词正文、参数、素材顺序、授权状态 | 模型/数量/时长/比例/声音和入口能力已核实 |
| 联合验收 | 运镜、动作、风格、技术四类记录 | 用户明确选择最终候选 |

状态统一使用 `PASS / FAIL / UNVERIFIED / NOT NEEDED`。`UNVERIFIED` 不是通过；技术解码成功也不是视觉通过。

## 3. storyboard.json

每个镜头至少包含：

- `shot_id`
- `duration_sec`
- `target_style`
- `scene_desc`
- `character_action`
- `start_state`
- `visible_result`
- `camera_motion`
- `camera_reference`
- `camera_acceptance`
- `author`
- `provenance`

示例见 `examples/storyboard.example.json`。未知焦距等信息应明确写为待定，不编造精确参数。

## 4. Blender 预演检查重点

### 几何与接触

- 相机和近裁剪面不进入人体、道具或地面。
- 人物不互穿，脚底不穿地或无因悬空。
- 手持、交接、释放和落地关系连续。
- 快速运动、擦碰、脱手、倒地和近距离掠过区间增加采样。
- 包围盒重叠只能用于定位疑点，不能直接当成穿模结论。

### 动作逻辑

- 每个关键事件都能看到“开始状态 → 实际执行 → 可见结果”。
- 走位距离、用时、步幅、支撑脚和加减速可信。
- 镜头遮挡或切镜不能隐藏关键因果。
- 每次导出新版都要观看实际视频并重新绑定文件哈希；旧版结论不能直接沿用。

### 运镜对照

逐项比较参考与预演的起止构图、机位高度、FOV、路径、主体占比、跟随距离、视差、加减速、运动模糊和衔接。没有实际轨迹时，只能声明属性级参考，不能承诺一比一复刻。

## 5. 风格参考与素材绑定

- 优先从已批准预演提取对应帧，再结合外观素材生成首帧或事件关键帧。
- 记录源预演路径、SHA-256、帧号、时间、图片职责和采用状态。
- 并排审核源预演帧与派生图，避免相机、数量、位置、朝向和接触关系漂移。
- 每份输入写清“解决什么缺口、适用哪个主体/阶段、移除后损失什么”。
- 预演提供运动、空间和运镜；风格图提供外观；不要让占位几何变成最终角色造型。

## 6. 提交与重试

提交前展示并确认：

```text
服务与模型：
模式：
视频数量：
单条时长：
画幅：
声音：
素材编号与顺序：
预计提交次数：
授权状态：
```

成功提交后记录 `request_id`、模型、参数、资产 ID、时间与状态。只轮询原任务。失败、任务消失或视觉不合格时先诊断；新的付费重试需要新的明确授权。

## 7. 最终验收

分别记录四类结论：

1. 运镜：路径、跟随、视差、加减速和衔接是否符合预演及参考。
2. 动作：身份、数量、接触、空间和“起始—过程—结果”是否完整。
3. 风格：开场、中段、交互和结尾是否都达到目标风格，是否残留低模或调试元素。
4. 技术：解码、时长、比例、分辨率、实际帧率和音轨。

只有用户明确选择的候选可以打包为最终版本。

## 8. 战场题材

战争、袭击、爆炸、撤离等题材还要读取 `references/battlefield-immersion.md`。该规则强调可见的压力链、人物受迫行动、持续逼近的威胁、事件触发的镜头冲击，以及关键因果不能被烟尘或震动遮掉。它不提供实拍爆破或真实武器反制参数。
